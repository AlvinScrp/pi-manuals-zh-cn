两份技术手册的全文简体中文译本，提供独立 HTML 阅读页面。

## 在线阅读

**[点击这里，打开中文手册阅读首页 →](https://alvinscrp.github.io/pi-manuals-zh-cn/)**

也可以直接选择手册：

- [阅读 Pi Durable Technical Manual 中文版](https://alvinscrp.github.io/pi-manuals-zh-cn/Pi-Durable-Technical-Manual.zh-CN.html)：对应原文 190 页。

点击上面的链接即可在浏览器中阅读，无需下载文件或安装软件。仓库 About 区域的 Website 链接也能进入阅读首页。

## 关于译本

网页保留原文的章节结构、数值、单位、代码及安全说明，并提供左侧目录、中文配图、原图对照和图片放大。图像、样式和脚本均包含在 HTML 中，可下载后离线阅读。

源文档为 `Pi-Technical-Manual.pdf` 和 `Pi-Durable-Technical-Manual.pdf`。本项目为中文翻译阅读版本。原文档及图像的权利归各自权利人所有。
