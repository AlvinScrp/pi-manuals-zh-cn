# Pi 技术手册中文译本

两份技术手册的全文简体中文译本，提供独立 HTML 阅读页面。

- [Pi Technical Manual](Pi-Technical-Manual.zh-CN.html)：对应原文 221 页。
- [Pi Durable Technical Manual](Pi-Durable-Technical-Manual.zh-CN.html)：对应原文 190 页。

网页保留原文的章节结构、数值、单位、代码及安全说明，并提供左侧目录、中文配图、原图对照和图片放大。图像、样式和脚本均包含在 HTML 中，可下载后离线阅读。

源文档为 `Pi-Technical-Manual.pdf` 和 `Pi-Durable-Technical-Manual.pdf`。本项目为中文翻译阅读版本。原文档及图像的权利归各自权利人所有。

## GitHub Pages

在仓库 Settings → Pages 中，选择 **Deploy from a branch**，分支选择 `main`，目录选择 `/ (root)`。首页为 `index.html`。
